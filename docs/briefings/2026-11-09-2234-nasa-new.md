## Decisions and why
- **Garden reveal is the "probe floodlights", not glowing chimneys or microbes.** Self-glow would imply bioluminescence, which isn't in the facts, and the decision log rules out visible light at 40–90 °C.
- **VT323 for body text, not Pixelify Sans.** In Pixelify, "2005" looked like "200S" and 122 like 128, and exact numbers matter for the science score.
- **Hook line is a question** ("Could anything live down here?"), so it makes no new claim.
- **Key terms** use `<strong class="term">` with a highlight rather than real bold, because VT323 has no bold weight.
- **Ownership split** (Codex: widgets; Claude: page, scene and HUD) avoids edit conflicts. Cross-file problems go under "Requests".

## Gotchas
- **The headless Playwright browser only advances animation frames while it's taking a screenshot.** The camera won't move unless you force frames (take throwaway screenshots in a loop). Measure with the `camOff()` and `settle()` helpers from the scripts.
- **Port 8765 is taken by another program on this computer.** Serve on **8917**: `npx http-server -p 8917 -c-1 .` (it may still be running). Codex uses 8918.
- **Playwright can only save files** inside the project folder or `.playwright-mcp/`, not the scratchpad.
- **Don't send a `Cache-Control` header** when testing the live site; Google Fonts rejects it. Use CDP `Network.setCacheDisabled` instead.
- **`#world` is a fixed layer moved by `translate3d`.** An element's page position is `getBoundingClientRect().top + cam`.
- **Widgets fire `window.dispatchEvent(new Event('resize'))`** when their height changes. `app.js` re-runs its layout 80ms later, debounced.
- **The live Google Doc report draft changes constantly.** Re-fetch it with:
  `curl -sL "https://docs.google.com/document/d/1dfwaelVOlmn2ipkfcNjAF0PC0saL--kXWCdKiPXRktU/export?format=txt"`
- **The old report outline** (`docs/text/report-outline-OLD.txt`) has an outdated 4-level food web. Don't use it.
